# Tectonic Releases\n\nAll releases are available on the [GitHub Releases](https://github.com/Grandsummoner/tectonic/releases) page.\n\n## Installing Tectonic\n\n### Windows\n1. Download `Tectonic-Windows.zip` from the latest release\n2. Extract the ZIP file\n3. Copy `Tectonic.vst3` folder to your VST3 plugin directory:\n   - `C:\\Program Files\\Common Files\\VST3` (system-wide)\n   - Or `%APPDATA%\\Local\\Programs\\Common Files\\VST3` (user-specific)\n4. Restart your DAW\n5. Scan for new plugins\n\n### macOS\n1. Download `Tectonic-macOS.zip` from the latest release\n2. Extract the ZIP file\n3. Copy `Tectonic.vst3` to your VST3 plugin directory:\n   - `/Library/Audio/Plug-Ins/VST3` (system-wide)\n   - Or `~/Library/Audio/Plug-Ins/VST3` (user-specific)\n4. Restart your DAW\n5. Scan for new plugins\n\n## Version History\n\nSee the [Releases](https://github.com/Grandsummoner/tectonic/releases) page for detailed changelogs.\n\n## System Requirements\n\n- **Windows**: Windows 10+ (x64)\n- **macOS**: macOS 10.13+ (Intel/Apple Silicon)\n- **DAW**: Any VST3-compatible DAW (Reaper, Studio One, Cubase 12+, etc.)\n\n## First Launch\n\nWhen you first load Tectonic:\n1. A default preset will be created automatically\n2. Presets are stored in:\n   - Windows: `%APPDATA%\\Tectonic\\Presets`\n   - macOS: `~/Library/Application Support/Tectonic/Presets`\n\n## Troubleshooting\n\n**Plugin not showing in DAW?**\n- Verify the VST3 folder is in the correct directory\n- Check that your DAW supports VST3 format\n- Try rescanning your plugin folder in DAW settings\n\n**Presets not saving?**\n- Ensure the Tectonic presets directory is writable\n- Check that you have sufficient disk space\n- Try manually creating the directory if it doesn't exist\n"
